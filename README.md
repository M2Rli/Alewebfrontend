# THE OP — Trading Workspace

واجهة عربية محسّنة لمشروع `M2Rli/Alewebfrontend`، مبنية على النسخة `ca2089a`.

## ما تغيّر

- صفحة رئيسية تجمع أدوات التداول، بدلاً من شاشة الانتظار الافتتاحية.
- تصميم فحمي بلمسة زرقاء وألوان نعناعية هادئة، وأيقونات SVG موحّدة.
- قسم لإدارة المخاطر يربط حساب الصفقة وحدّ الخسارة اليومي ومراجعة السجل.
- طبقات مجسّمة ورمز درع لإدارة المخاطر، مع دخول تدريجي للبطاقات وإيقاف حركة المشهد خارج الشاشة أو عند إخفاء الصفحة.
- مشهد شارت مجسّم بـ CSS 3D، مع حركة هادئة وتفاعل مع مؤشر الماوس. المشهد توضيحي وليس بيانات سوق.
- زر لإيقاف الحركة، مع احترام إعداد تقليل الحركة في الجهاز وحفظ اختيار المستخدم.
- مدخلات الحاسبة ونتائجها في عمودين على الكمبيوتر، وترتيب عمودي على الهاتف.
- تصميم متناسق للأسعار، تحليل الصورة، حد الخسارة، التقارير، الحساب ولوحة الإدارة.
- خطوط Cairo وJetBrains Mono محلية، مع تراخيصها، دون انتظار Google Fonts.
- تحسين استخدام لوحة المفاتيح، تسمية الحقول، وإغلاق نافذة الحساب.
- إزالة الرسوم العشوائية الصغيرة بجانب الأسعار لأنها لم تكن مبنية على تاريخ أسعار فعلي.

## الملفات

- `index.html`: الصفحات والحاسبة والوظائف الموجودة.
- `experience.css`: التصميم الجديد ومقاسات الشاشات والحركة.
- `experience.js`: تفاعل المشهد، إعداد الحركة وتحسينات التنقّل.
- `app-auth.js`: ربط الحساب الموجود مع تصميم النافذة وشريط الحساب.
- `admin.html`: لوحة الإدارة بألوان متناسقة.
- `assets/fonts/`: الخطوط المحلية وتراخيصها.
- `config.js` و`vercel.json`: إعدادات المشروع الأصلية؛ لم تتغيّر.

المشروع ما زال HTML/CSS/JavaScript عاديًا. لا يحتاج npm أو عملية build جديدة.

## المعاينة على جهازك

من داخل مجلد المشروع، شغّل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. على بعض الأجهزة استخدم `python3` بدل `python`.
الأسعار التي تعتمد على إعادة توجيه Vercel لا تعمل من خادم Python المحلي؛ اختبرها على Vercel Preview.

## إضافته إلى GitHub وVercel

1. فك ضغط النسخة المعدّلة على جهازك.
2. افتح مستودع `M2Rli/Alewebfrontend`، وأنشئ فرعًا جديدًا للتصميم.
3. ارفع الملفات المعدّلة وملفَي `experience.css` و`experience.js` ومجلد `assets` إلى جذر المشروع، بجانب `index.html`.
4. راجع معاينة الفرع على Vercel إذا كان توليد المعاينات مفعّلاً.
5. جرّب تسجيل الدخول والاشتراك والأسعار والتحليل بحسابك، ثم ادمج الفرع لنشر النسخة عند تفعيل النشر التلقائي.

إذا تغيّر المستودع بعد `ca2089a`، ادمج التعديلات مع النسخة الأحدث بدل استبدال ملفاتها بالكامل.
هذه الحزمة وحدها لا تغيّر الموقع المنشور، ولا تنشر أي تعديل تلقائيًا.

## التحقق الذي أُنجز

- تشغيل الصفحات السبع والتنقّل بينها دون أخطاء JavaScript في المتصفح.
- حسابات Long وShort وForex، والتحقق من وقف خسارة غير صالح.
- حفظ صفقة في السجل، استمرارها بعد إعادة التحميل، وتصدير JSON.
- معاينة صورة الشارت بعد رفعها، دون تنفيذ تحليل مدفوع.
- نافذة تسجيل الدخول وEscape واستعادة تمرير الصفحة؛ جلسة الحساب كانت محاكاة محلية للاختبار.
- تفاعل 3D، حفظ إيقاف الحركة، واحترام `prefers-reduced-motion`.
- الصفحات السبع بعرض 320 و390 و768 و1024 و1440 بكسل دون تمرير أفقي غير مقصود.

اختبارات الواجهة عطّلت الشبكات الخارجية عمدًا؛ لذلك تظهر رسالة تعذّر الأسعار في بعض صور المعاينة.
لم يُختبر تسجيل دخول حقيقي أو اشتراك/دفع أو تحليل مدفوع. لم تتغيّر معادلات الحاسبة أو مسارات API.
